## Behavior detail

- **Sounds: none.** The mod ships no `sounds.json`/`sound_definitions` and no `.ogg`/`.wav` files at `95bb61d` (verified against the full resource tree; `git ls-tree -r 26.2` finds no `sounds`, `.ogg` or `.wav` path); all feedback is silent (UI clicks use vanilla defaults where any).
- **GUI backgrounds** are drawn by the screens (areas `02`/`03`); `storage_terminal.png` is the base terminal texture that the tall terminal stretches row-by-row (the row strip is a region of the same texture — the stretch logic is in `AbstractStorageTerminalScreen`, area `03-terminal`).
- **Icon sprites** are referenced by name from the widget kit: `EnumCycleButton` builds `icons/<prefix>_<enum>` ids for the `sort_*`, `control_*`, `priority_*`, `side_*` sets; `ToggleButton`s in the screens use `keep_last_*`, `match_tag_*`, `lock_*`, `refill_*`, `tall_terminal_*`; `TerminalSearchModeButton` stacks `search_mode*` overlays.
- **Widget sprites** are the only sprites with nine-slice mcmeta, enabling the 16×16 icon buttons and 106-px-wide list rows to stretch crisply.
- **Block/item textures and models:** the 20 block textures, 7 item textures, 17 block models, 8 item models, and 15 blockstates are listed in [COVERAGE.md](../COVERAGE.md) under areas `02-storage`/`03-terminal`/`04-wireless` (the sheets that document each block/item own their textures/models); they are not re-listed here.
